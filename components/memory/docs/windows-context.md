# Windows 自动上下文

安装服务后，运行 `node scripts/enable-desktop.mjs` 并重启 Memory 服务即可启用。默认新安装不自动开启这一项；本次用户已明确要求扩展范围，因此当前部署已开启。

服务启动隐藏采集进程，每 5 秒观察前台窗口，记录当前应用、窗口/文档标题以及 Windows UI Automation 可读取的非编辑可见文字。只采集发生变化的上下文，记录最短间隔 15 秒，相同内容 5 分钟内去重。读取页面文字受节点数量和时间预算限制；读取失败时仅保留通过过滤的应用/窗口标题。

不会拦截键盘逐字输入、读取输入框/密码框、拍摄屏幕或访问 App 私有数据库。锁屏、安全桌面、密码管理器、认证器、终端及识别出的登录、支付、银行、验证码和无痕页面被跳过。识别依赖程序/页面暴露的标记和文字，可能漏识别或误过滤。浏览器、Office、聊天 App 的内容覆盖依赖其可访问性，不代表每个点击、每条消息和整个文档都能读取。

暂停电脑服务也会停止采集。隐藏子进程检测所属服务退出后自行结束；UI 读取挂起超过 60 秒时服务会回收这个采集子进程并尝试恢复。状态在本机 `state/desktop-capture.json`，不包含页面内容。

桌面服务和托盘仍采用已有的当前用户登录自启方案。手机和电脑新增范围均保留过滤和暂停入口。
