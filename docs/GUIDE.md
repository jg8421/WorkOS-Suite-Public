# WorkOS Suite 1.0.2 使用案例

## 项目研究：从资料到可修订交付

以虚构的 **Demo Robotics（合成示例）** 为例，在 WorkOS 建立项目，在文件页添加自己准备的合成资料文件夹。这个名称、资料及后续演示输入均不代表真实公司或业务。点选一份 Excel、PDF 或会议文字，先看内容是否正确，再送到项目。文件不会自动被发送给外部模型；同一项目重复导入未改动文件会复用记录，修改后的文件保存为新版本。

在 WorkOS 选定资料，直接写「解释收入增长的主要驱动，给我简要结论和待确认的问题」。模型选择保留原 WorkOS 的统一目录。缺少退出年份、投入日期或净利润口径时，在原对话补充自然语言；不需要自己编辑 JSON。回报模型仍要求明确实际假设，原生 Excel 是否可重算取决于本机安装条件。

写「基于刚才结果改成投委会讨论材料，结论更短，保留来源」继续同一任务。版本、上下文和交付能力由原 WorkOS 保存。正式保存到项目文件夹的规则在 WorkOS 中配置；Suite 的想法库与记忆库是另外的本机持久存储。

## 临时想法：先保存，再归档

在想法页随手写一句话，Enter 保存，Shift+Enter 换行。不选项目也可保存，草稿在切换模块和刷新后保留。点击「送到项目」，选项目，生成真实项目笔记；原想法继续保留。重复送入同一项目会复用笔记，删除原想法不会删除已生成的项目笔记。

原版 Idea Collector 在同页的「原版工具」中可用，浏览器目录授权与其历史数据继续遵循原工具的规则。

## 文件整理：键盘、真实文件剪贴板与撤销

添加一个完整文件夹路径作为访问范围。浏览、搜索、预览均限制在这些已登记目录内；跳出目录的链接和路径会被拒绝。新建目录、重命名、复制和移动均不覆盖已有目标。

单击选择与预览，↑ / ↓ 切换文件；Ctrl / Shift + 点击可以多选，Ctrl + A 全选当前列表。Enter 或双击进入文件夹；对文件会交给 Windows 原应用打开。Alt + ← / → 后退或前进，Alt + ↑ 或 Backspace 回到上一级。输入框、中文组词和弹窗中保留原有键盘行为。

Ctrl + C / X 复制或剪切真实文件，既可在工作台目标目录 Ctrl + V，也可粘贴到 Windows 资源管理器；微信等支持文件粘贴的应用也可接收复制文件。工作台可在已登记目录间转移多项文件，同名复制会生成新名称，移动遇到同名目标会保留原文件并提示。F2 重命名一项，Delete 确认后移至回收区，Ctrl + Z 撤销上次回收。选中文字时 Ctrl + C 仍复制文字。

搜索框输入时只筛选当前层文件名；按 Enter 或「深入搜索」才搜索当前目录的子目录名称及可提取正文。支持文本、PDF、DOCX、PPTX 和 XLSX 内容片段，命中会显示名称或正文位置。搜索有时间、文件数和读取量上限；遇到大文件、扫描 PDF、损坏文件或超限时，请查看「结果不完整」提示，不能把无命中当成所有资料都没有该内容。

删除会转移到套件自己的回收区，页面提供撤销。不是永久删除。遇到 OneDrive 同步或 Office 占用，先保存或等待同步，再重试。网页文件页提供受限文本、表格或压缩包清单预览，不执行 HTML，也不做 OCR。

需要原版 PDF 视觉阅读、MSG、ZIP 内文件预览或 Markdown / Excel 编辑时，点击「打开完整文件工作台」。入口先检查本机或完整包的 Tk 和文件依赖，缺失时显示具体原因。它打开完整原版独立窗口，使用原工具自己的目录、收藏和设置，不自动沿用网页当前目录；可在窗口内直接选文件夹。Office 原生渲染和 Excel 编辑仍需本机 Office。退出 Suite 不关闭这个窗口，请在原窗口保存后自行退出。

## 千问录制

安装并登录官方千问 Windows 客户端，并在千问中确认录音快捷键。在「监听应用、快捷键与诊断」中选需要监听的通话应用、填写相同快捷键，保存后再启动监听。应用启动不等于进入通话；自动触发由实际音频与防重复规则判断。

如果这台机器已经运行原千问监听，Suite 连接其真实状态与既有配置，页面会显示「已连接原监听服务」，不启动第二套。可以暂停、恢复监听或手动触发；页面分别显示通话检测、等待触发和千问实际录音状态。发送快捷键成功不等于录音成功，未开始时检查客户端登录、麦克风/播放音频及快捷键。

新安装默认不监听，打开此页只读取状态。Suite 保存过明确启用状态后，下次启动会恢复自己的监听；已有原监听继续遵循原工具的开机启动配置。暂停或停止监听不会结束千问里已经开始的录音，实际录音要在千问中停止。退出 Suite 不会关闭借用的原监听。

归档列表显示当前监听来源已有的归档。完成会议文字可通过文件页送入项目，再在 WorkOS 整理和继续修订。录音与归档以实际状态和文件为准，不能仅凭触发请求成功判断完成。

## 手机与进程

Android 先开启开发者选项、USB 或无线调试，再授权电脑。无线配对码地址与实际连接地址不同：先配对，再填无线调试主页面的连接地址。选择明确设备后开始镜像；截屏按需进行。停止只关闭由套件启动的镜像。当前采用官方 ADB 配对码流程，没有宣称旧自定义二维码配对协议可用。

进程页显示真实资源数据，首次 CPU 采样或未接入的硬件温度显示「—」。结束、暂停或调整优先级前，工作台核对 PID 与创建时间；受到保护的系统、工作台和组件进程不能在这里操作。不要结束正在编辑未保存文件的程序。

当前统一进程页提供 PID 级控制和 CPU/内存信息。点击「打开完整进程管理器」可使用原版独立界面的功耗、温度传感器与历史图表；真实传感器仍取决于本机硬件、驱动和可选监控源，缺失指标不会用估算值代替。原版窗口的操作由你直接控制，退出 Suite 不关闭它。

## 记忆与换机器

先保存一条偏好，例如「邮件要短，开头直接说请求，Memo 的事实要带来源」。搜索和遗忘在本机完成，遗忘为软删除。Codex、DSH、桌面采集和云收件箱导入默认关闭，需要时主动开启。会话导入目前保留支持的用户消息，不导入助手回复或系统/工具载荷；云收件箱只导入已到达该服务本地收件目录、通过校验的 Android 批次，开启开关本身不会连接手机或登录云账号。记忆不会自动变成项目事实，也不会自动外发。

Suite 记忆服务使用自己的数据目录，打开页面不会自动导入原记忆库。原组件的 MCP、手机网关或 OneDrive/Graph 同步仍需各自配置与授权；本机搜索成功不代表云端同步完成。WorkOS 的项目经验另按项目与用途保存，和这个通用记忆库分开。

新机器只需解压完整包并双击启动；模型、千问和手机仍需登录授权。迁移个人内容请单独备份 `%LOCALAPPDATA%\WorkOS-Suite`，先退出套件再复制。若使用外部 WorkOS，另行备份其数据目录；发行包不包含你的个人数据库或密钥。
