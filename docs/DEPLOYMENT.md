# Windows 一键启动

完整解压 `WorkOS-Suite-…-windows-x64-complete.zip` 到自己的目录，双击 `启动.cmd`。套件会检查内置环境并打开统一工作台，默认仅监听本机 `127.0.0.1:18880`。无需预装 Python、Node、pip 或 pnpm，不修改系统 PATH、其他软件或开机启动项。遇到问题可双击 `环境检查.cmd`。

退出时双击 `停止.cmd`（英文为 `Stop-Suite.cmd`）。启动器先确认该端口确实是 WorkOS Suite，再携带当前会话校验发送退出请求并等待服务关闭；不会使用 taskkill、进程名或旧 PID 强杀其他应用。

公开便携包包含七项软件的固定版本源码和统一网页适配器：WorkOS、文件工作台、进程管理、千问自动录音、手机镜像、想法收集器、个人记忆。记忆组件只包含通用程序，不包含任何人的记忆内容。Python 3.13.12、Node 24.21.0、完整导出/录音/配对依赖、官方 ADB 与 scrcpy 均随包提供。固定版本、官方来源和哈希记录在 `runtime-lock.json`，每个交付文件的哈希在 `package-manifest.json`。源项目的旧 Tk 窗口保留为参考源码；套件默认使用统一网页功能，便携 Python 不包含 Tk。

个人数据、日志和新配置写入 `%LOCALAPPDATA%\WorkOS-Suite`。安装包不含任何用户录音、记忆、业务数据库、API key、模型或千问账号、手机配对信息。没有自动复制或删除旧数据：已有健康 WorkOS 服务可由统一入口借用；借用服务不会被套件停止。新机器会创建自己的空数据目录。需要旧资料时通过界面明确选择原目录或导入备份，保留原文件。

文件访问范围由使用者在文件页登记自己的目录；安装包没有预置个人或组织的 OneDrive 根目录。项目交付目录在 WorkOS 中单独配置，源资料不会被安装器迁移。

## 在这台机器上完成一次授权

- AI：在工作台设置自己的模型服务或自定义端点与凭证。账号、DSH 安装和登录不从打包机器迁移；未配置时不宣称模型已调用。
- 录音：安装并登录官方千问 PC 客户端，确认系统麦克风权限；在界面明确启用自动化。停止套件自动化不等于结束千问正在进行的原生录音，请在千问里停止。
- 手机：使用自己的 Android 手机，在手机上启用 USB 调试并确认授权，或完成无线配对。套件不会扫描整个局域网、断开其他设备或结束共享 ADB 服务。无线调试、USB 驱动、网络和手机系统权限属于外部条件。
- 记忆：手动记录和本地检索可使用内置服务。自动电脑上下文/会话导入、手机通知/无障碍采集必须分别启用并授权；默认不会开始私人信息采集。手机安装包在 `app/components/memory/releases/`。OneDrive/公网/Graph 等同步需要自己的服务与账号配置，本地入库不代表云端同步完成。
- Office：DOCX/PPTX/XLSX 文件生成依赖已经包含。原生 Office 预览及 Excel 投资回报重算需要本机 Office。没有 Excel 时保留假设与文件结构，不显示假装算过的原生结果。

## 运行管理与备份

后台组件只接受套件源码注册的固定启动动作。停止和重启只针对套件启动并核对创建身份的进程及其子进程，不按可执行文件名批量结束程序；已在外部运行的组件显示借用状态。运行状态与阶段事件不会公开命令参数、凭证或日志正文。

备份自己的数据目录及应用提供的导出。更新时使用新的解压目录，保留旧包和个人数据；不要将私有数据目录混入通用软件包。`preview` 文件名/清单表示工作源码预览，不等于已发布；正式清单必须含 clean Git HEAD 的来源提交。
