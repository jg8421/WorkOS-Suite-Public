# WorkOS Suite 1.0.4 Windows 一键启动

完整解压 `WorkOS-Suite-1.0.4-windows-x64-complete.zip` 到自己的目录，双击 `启动.cmd`。套件会检查内置环境并打开统一工作台，默认仅监听本机 `127.0.0.1:18880`。无需预装 Python、Node、pip 或 pnpm，不修改系统 PATH、其他软件或开机启动项。遇到问题可双击 `环境检查.cmd`。

退出时双击 `停止.cmd`（英文为 `Stop-Suite.cmd`）。启动器先确认该端口确实是 WorkOS Suite，再携带当前会话校验发送退出请求并等待服务关闭；不会使用 taskkill、进程名或旧 PID 强杀其他应用。

公开便携包包含七项软件的固定版本源码和统一网页适配器：WorkOS、文件工作台、进程管理、千问自动录音、手机镜像、想法收集器、个人记忆。记忆组件只包含通用程序，不包含任何人的记忆内容。Python 3.13.12、Node 24.21.0、完整导出/录音/配对依赖、官方 ADB 与 scrcpy 均随包提供。固定版本、官方来源和哈希记录在 `runtime-lock.json`，每个交付文件的哈希在 `package-manifest.json`。套件默认使用统一网页，文件与进程页另外提供受控的完整原版 Tk 窗口入口；可用性取决于实际 Tk 与依赖检查，缺失时不会显示成已可用。

个人数据、日志和新配置写入 `%LOCALAPPDATA%\WorkOS-Suite`。安装包不含任何用户录音、记忆、业务数据库、API key、模型或千问账号、手机配对信息。没有自动复制或删除旧数据：已有健康 WorkOS 服务可由统一入口借用；借用服务不会被套件停止。新机器会创建自己的空数据目录。需要旧资料时通过界面明确选择原目录或导入备份，保留原文件。

文件访问范围由使用者在文件页登记自己的目录；安装包没有预置个人或组织的 OneDrive 根目录。项目交付目录在 WorkOS 中单独配置，源资料不会被安装器迁移。1.0.4 恢复文件键盘导航、多选、跨目录复制/移动、Windows 文件剪贴板、原应用打开与有界递归内容搜索；快捷键与预览范围见 [使用指南](GUIDE.md)。系统文件剪贴板和原应用打开仅接受本机同源请求，所有路径仍须在登记范围内。

## 明确选择研究数据和公网入口

默认启动仍为本机模式，可借用已在 18866 运行的健康 WorkOS。指定 `--core-data-dir` 后会启动使用该目录的独立研究后台，不再借用旧服务。选择现有数据目录前，应先安全退出持有该目录的后台；发现原服务仍占用同一目录，或另一个 Suite 已持有该目录时会拒绝启动，不自动停止它们。不能同时运行两个实例读写同一份 SQLite。新目录会建立空工作区，不会自动复制另一份数据。

启动器支持 `--core-data-dir`、`--sync-root`、`--remote-config`，或本机部署配置 `--profile`。未传 `--profile` 时，读取 Suite 数据目录内的 `deployment.json`；未配置则保持默认本机行为。配置只接受以下三个字段的绝对路径，路径需要按本机实际位置填写，不随安装包预置：

```json
{
  "core_data_dir": "C:/WorkOSData/core",
  "sync_root": "C:/OneDrive/WorkOSShared",
  "remote_config": "C:/WorkOSData/remote.json"
}
```

这是路径示例，`C:/OneDrive` 不会自动变成已登录的 OneDrive。可只配置需要的字段。便携包可在其根目录执行 `runtime\python\python.exe -I -B app\tools\deployment_preflight.py --start --profile "<本机部署配置JSON的绝对路径>"`；使用默认 `deployment.json` 后，仍可双击普通启动器。修改启动配置前先正常停止当前 Suite；已运行的实例会被复用，不会被配置命令悄悄替换。

公网配置另存为本机 JSON，严格只接受 `origin` 和 `authentication_dir`：

```json
{
  "origin": "https://suite.example.invalid",
  "authentication_dir": "C:/WorkOSData/core/authentication"
}
```

示例域名不能直接访问，应替换为自己控制的固定 HTTPS 地址。`authentication_dir` 必须是选定研究数据目录下的 `authentication`，且账户已初始化；配置中不写明文密码或令牌。先用选定 `core_data_dir` 在本机启动，在本机 `/auth/setup` 设置密码，正常退出后再启用公网配置。账户哈希与登录会话保存在本机，密码更改使旧会话失效。

隧道、域名和 HTTPS 由使用者单独配置，目标为本机 Suite 入口，默认 `127.0.0.1:18880`；设置 `origin` 不会安装隧道或注册域名。公网页面要求登录，修改操作使用会话 CSRF。已登记资料可远程浏览、搜索、下载及在登记范围内整理；研究、交付、想法及主动记忆记录使用这台主机的数据。进程、手机、录音控制、系统文件剪贴板、原应用/原版窗口启动、目录登记和账户/模型等主机配置仍只允许在本机操作。不要将公网地址替换成任意客户端提供的 Host 或 Origin。

## OneDrive 与另一台机器

每台机器需登录同一 OneDrive 账户，并登记该机器实际同步目录。文件页与项目交付目录可以使用这些文件，但本地写入和应用的 `last_sync` 不证明微软云端上传已经完成。

显式 `sync_root` 让 WorkOS 导出可阅读项目资料、归档原件和可重建 JSON 快照；SQLite/WAL 仍在本机。只有空工作区启动时自动读取快照；非空工作区不会持续拉取远端修改。手动备份恢复会替换记录，不能当作增量合并。镜像不包含 Suite 想法/目录登记、后台任务队列、对话数据库、项目经验和账户配置；对话及项目经验有各自的导出入口，需要单独备份。

当前应使用一个指定设备写入同一 WorkOS 镜像。两台机器分别运行并同时同步到同一根目录会覆盖快照，保留的历史文件也不会自动合并冲突。需要继续使用同一工作状态，可登录同一台主机的受保护远程入口；需要换机则先备份、退出旧后台，再显式迁移或恢复。不要将运行中的 SQLite、WAL、登录会话或认证目录放进 OneDrive。

Suite 记忆服务使用独立本机目录，云收件箱开关只导入已到达该目录的有效 Android 批次。原 Memory 组件另有可配置的 OneDrive 数据根及手机 Graph 授权：它支持不可变手机批次和稳定来源编号去重，但不等于多台电脑共同编辑主日志与删除状态的冲突合并。原组件账号和目录配置需分别完成，不能共写同一个 `events.jsonl` 来替代同步协议。

## 在这台机器上完成一次授权

- AI：在工作台设置自己的模型服务或自定义端点与凭证。账号、DSH 安装和登录不从打包机器迁移；未配置时不宣称模型已调用。
- 录音：安装并登录官方千问 PC 客户端，确认系统麦克风权限与实际录音快捷键；在界面设置监听应用并明确启动。已有原监听会被验证并借用，保留其配置和开机启动行为；新机器默认关闭。Suite 保存过明确启用状态后会在下次启动恢复自己的监听，但不创建系统开机任务。暂停/停止监听不等于结束千问正在进行的原生录音，请在千问里停止。界面区分已发送触发请求与已观察到实际录音，不能用前者替代后者。
- 手机：使用自己的 Android 手机，在手机上启用 USB 调试并确认授权，或完成无线配对。套件不会扫描整个局域网、断开其他设备或结束共享 ADB 服务。无线调试、USB 驱动、网络和手机系统权限属于外部条件。
- 记忆：手动记录和本地检索可使用内置服务。自动电脑上下文/会话导入、手机通知/无障碍采集必须分别启用并授权；默认不会开始私人信息采集。手机安装包在 `app/components/memory/releases/`。OneDrive/公网/Graph 等同步需要自己的服务与账号配置，本地入库不代表云端同步完成。
- Office：DOCX/PPTX/XLSX 文件生成，以及文件页受限文本/表格预览的依赖已经包含，无需安装 Office。用原应用打开需要相应的本机文件关联；完整文件工作台的原生 Office 渲染、Excel 编辑和 WorkOS 原生 Excel 投资回报重算需要本机 Office。没有 Excel 时保留假设与文件结构，不显示假装算过的原生结果。
- 完整原版窗口：文件工作台需要 Tk/Tcl、PyMuPDF、Pillow、tksheet、openpyxl、Markdown 与 tkinterweb；进程管家基础界面需要 Windows 与 Tk，可选 pywin32 / 本机传感器提供功耗和温度。入口优先检查随包 Python，再检查专用或已登记的本机 Python。只启动固定的两个程序，不接受网页传入运行环境、脚本或命令；不下载或自动安装 host 依赖。窗口独立运行，使用原工具设置，退出 Suite 不关闭未保存编辑。

## 运行管理与备份

后台组件只接受套件源码注册的固定启动动作。停止和重启只针对套件启动并核对创建身份的进程及其子进程，不按可执行文件名批量结束程序；已在外部运行的组件显示借用状态。运行状态与阶段事件不会公开命令参数、凭证或日志正文。借用原千问监听时，「暂停监听」控制其监听状态，退出 Suite 保留原服务；正在录音的千问客户端也会保留。

备份自己的数据目录及应用提供的导出。更新时使用新的解压目录，保留旧包和个人数据；不要将私有数据目录混入通用软件包。`preview` 文件名/清单表示工作源码预览，不等于已发布；正式清单必须含 clean Git HEAD 的来源提交。

第三方许可证保留于 Python 的 `.dist-info`、Node/npm 与记忆依赖包、手机工具的原始 LICENSE/NOTICE；详见交付根目录 `THIRD-PARTY-NOTICES.md`。Microsoft Office、千问、设备驱动和外部账号遵循各自授权。
